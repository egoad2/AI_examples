

# AI 101 - Local AI and RAG Labs

This repository contains a series of hands-on Jupyter notebooks that introduce students to running AI models locally and building Retrieval-Augmented Generation (RAG) applications.

## Getting Started

These labs are designed to be opened directly in Google Colab. Click the appropriate badge below to launch the notebook.

### Lab 1: Introduction to Local Language Models

Learn how to load and interact with a local Large Language Model (LLM) using Python. This lab introduces the basic concepts of local inference and prompt engineering.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/egoad2/AI_examples/blob/main/AI_101/AI_101_Local_LLM.ipynb)

---

### Lab 2: Advanced Local LLM Usage

Build on the concepts from Lab 1 by exploring additional models, capabilities, configuration options, and practical workflows.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/egoad2/AI_examples/blob/main/AI_101/AI_102_Local_LLM.ipynb)

---

### Lab 3: Retrieval-Augmented Generation (RAG)

Learn how to improve AI responses by providing external knowledge sources. This lab introduces document loading, embeddings, vector databases, and Retrieval-Augmented Generation (RAG).

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/egoad2/AI_examples/blob/main/AI_101/AI_103_RAG.ipynb)

---

## Instructions

1. Open the notebook using the **Open in Colab** button.
2. Select **File → Save a Copy in Drive**.
3. Run each cell from top to bottom.
4. Complete any exercises or challenges included in the notebook.
5. Save your work regularly.

## Learning Objectives

After completing these labs, students should be able to:

- Explain the role of Large Language Models (LLMs)
- Run and interact with AI models using Python
- Understand the benefits and limitations of local AI
- Describe the purpose of embeddings and vector databases
- Build a basic Retrieval-Augmented Generation (RAG) workflow
- Evaluate AI-generated responses using external knowledge sources
